**🔗 [Repository](https://github.com/samrudhikulkarni05/StorePulse) • [YouTube Demo](https://youtu.be/n92wz_XYztc?si=cj5n9Fd5duZNirV5)**

A production-grade full-stack application with role-based access control, merchant onboarding, and analytics dashboards.

**Problem Solved:** Traditional store directories lack interactive customer-merchant-admin ecosystems for discovery, ratings, and moderation.

- 🏪 Merchant onboarding with moderation workflow

- 📊 Role-specific analytics dashboards
- 🔍 Advanced search, filtering, and sorting
- 🔐 Bcrypt password hashing & secure sessions

**Technologies:** React • TypeScript • Node.js • Express.js • Tailwind CSS • JWT
